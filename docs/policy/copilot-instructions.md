# POL-003 — Copilot Instructions

Every repository must have a `copilot-instructions.md` that states how to use GitHub Copilot in the repository. GitHub's conventional locations (repository root, `.github/`, or `docs/`) all satisfy this.

Each repository's `copilot-instructions.md` must be based on the org-level `.github/copilot-instructions.md` and may add repo-specific instructions as needed. The org-level instructions are maintained by the org admins and are updated as needed to reflect best practices for using Copilot in this organization.
