# POL-002 — Security Contact

Every repository must have a `SECURITY.md` that states how to report a security vulnerability privately. GitHub's conventional locations (repository root, `.github/`, or `docs/`) all satisfy this.

This policy must be enacted by every code repo of this organisation, if you do not comply you should fix this ASAP.
